# Currency Converter (Java - NetBeans GUI)

A simple **Currency Converter** application developed in **Java** using **Apache NetBeans**. It allows users to convert between different currencies using fixed exchange rates.

## Features
- Graphical User Interface (GUI) built using **Swing and NetBeans GUI Builder**.
- Convert between multiple predefined currencies.
- Simple and user-friendly design.
- Uses **fixed exchange rates** (No API required).

## Technologies Used
- **Java (JDK 8+)**
- **Apache NetBeans IDE**
- **Swing (for GUI)**
